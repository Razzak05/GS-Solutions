# GS Solutions — Enterprise Lead Generation & Dedicated Contact Centers

Precision live transfers, verified consumer qualification, and dedicated contact center operations engineered for high-performance sales floors in insurance, legal advocacy, and home services.

---

## 🚀 Key Verticals
- **ACA (Affordable Care Act)**: Subsidy-eligible individuals & working families.
- **Final Expense Life Insurance**: Target senior demographic (50–80) with payment capability.
- **Medicare Advantage & Supplement**: AEP, OEP, and year-round D-SNP dual-eligible transfers.
- **SSDI Disability Advocacy**: Unrepresented disability claimants out of work 12+ months.
- **Home Improvement & Solar**: Single-family homeowners pre-screened for utility minimums.
- **Omnichannel BPO & Support**: Inbound care, ticketing, and dedicated pod staff.

---

## ⚡ Features
- **100% TCPA & DNC Compliance**: Scrubbed with Jornaya & TrustedForm token verification.
- **Transparent Buffer Window**: 90–120s buffer credit guarantee for disconnected or unqualified calls.
- **Turnkey CRM Integration**: Webhooks & SIP routing for GoHighLevel, VICIdial, Salesforce, RingCentral, HubSpot.
- **Interactive Floor Capacity Estimator**: Dynamic modeling tool for daily transfer volume and rep pacing.

---

## 🛠️ Tech Stack & Getting Started

- **Frontend**: Modern Semantic HTML5, Vanilla CSS3 (Obsidian Design System & CSS Grid), JavaScript (ES Modules).
- **Bundler / Dev Server**: Vite

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
