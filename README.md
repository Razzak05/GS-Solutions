## 🚦 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm / yarn / pnpm

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Razzak05/GS-Solutions.git

# Navigate to project directory
cd GS-Solutions

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
